**Jogo de Adivinhação**

Jogo desenvolvido em Java durante a disciplina de Algoritmo e Lógica de Programação, no curso de Desenvolvimento de Software Multiplataforma (DSM) – FATEC ZL.
O programa sorteia um número de 0 a 10 e o jogador possui 3 tentativas para acertá-lo, recebendo dicas durante o jogo.

**Tecnologias**
- Java
- IntelliJ IDEA

**Conteúdos praticados**
- Variáveis e tipos de dados
- Estruturas condicionais
- Estrutura de repetição do while
- Conversão de dados
- Números aleatórios
- Entrada e saída de dados com JOptionPane
